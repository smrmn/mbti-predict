# MBTI Predict Bot

Telegram-бот, который определяет MBTI-тип пользователя через тест и каждый день присылает персонализированное предсказание, сгенерированное через AI API.

---

## Механика

### 1. Первый запуск (`/start`)

1. Бот приветствует пользователя.
2. Если профиль ещё не создан — предлагает пройти MBTI-тест (кнопка «Пройти тест»).
3. Если профиль уже есть — напоминает тип и предлагает перепройти тест (`/test`).

### 2. MBTI-тест

- 16 вопросов, по 4 на каждую из четырёх шкал:

| Шкала | Полюса |
|-------|--------|
| E / I | Экстраверсия / Интроверсия |
| S / N | Сенсорика / Интуиция |
| T / F | Логика / Этика |
| J / P | Рациональность / Иррациональность |

- Каждый вопрос отправляется отдельным сообщением с **inline-кнопками** (варианты A и B прямо под постом).
- Прогресс хранится в **FSM (Finite State Machine)** aiogram — бот помнит, на каком вопросе находится пользователь.
- После 16-го вопроса бот подсчитывает результат, определяет тип (например, `INFP`) и сохраняет его в профиль.
- Пользователь получает сообщение с результатом и кратким описанием типа.

### 3. Хранение профилей

Профили хранятся локально в папке `/profiles/` в виде JSON-файлов:

```
profiles/
  12345678.json   → {"mbti": "INFP", "registered_at": "2026-05-26"}
  87654321.json   → {"mbti": "ENTJ", "registered_at": "2026-05-25"}
```

Ключ — `user_id` пользователя в Telegram. Профиль перезаписывается при повторном прохождении теста.

### 4. Ежедневные предсказания

- **APScheduler** запускает задачу каждый день в заданное время (по умолчанию 9:00 МСК).
- Для каждого пользователя из `/profiles/` генерируется уникальное предсказание через **Claude / OpenAI API** с учётом его MBTI-типа.
- Промпт: персонализированное вдохновляющее сообщение на день, 3–4 предложения, тёплый тон, конкретный совет.
- Готовое сообщение отправляется пользователю в Telegram.

### 5. Команды

| Команда | Действие |
|---------|----------|
| `/start` | Приветствие. Запускает тест, если профиля нет |
| `/test` | Перепройти MBTI-тест (результат перезапишет старый) |
| `/profile` | Показать текущий MBTI-тип |
| `/predict` | Получить предсказание прямо сейчас (вне расписания) |

## Быстрый старт

```bash
# 1. Клонировать / перейти в папку проекта
cd mbti-predict

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Настроить переменные окружения
cp .env.example .env
# Отредактировать .env: вставить BOT_TOKEN и ANTHROPIC_API_KEY

# 4. Запустить бота
python bot.py
```

## Переменные окружения (`.env`)

```
BOT_TOKEN=your_telegram_bot_token
ANTHROPIC_API_KEY=your_anthropic_api_key
DAILY_HOUR=9        # Час рассылки (МСК, 24h формат)
DAILY_MINUTE=0      # Минута рассылки

# Слежение за обменом ETH ↔ WBTC (без SWAP_OWNER выключено)
SWAP_OWNER=username      # username владельца: только ему /swap, /bought и уведомления
SWAP_ETH_AMOUNT=10       # стартовая позиция: сколько ETH на руках
SWAP_WBTC_BASE=0.3       # и сколько WBTC за них отдали
SWAP_GAIN_PCT=2          # порог выгоды, %
SWAP_TRAIL_PCT=1         # откат от пика, п.п.
SWAP_FEE_PCT=0.875       # комиссия кошелька за обмен (MetaMask Swaps), %
SWAP_CHECK_MINUTES=5     # как часто проверять курс до порога
```

### Слежение ETH ↔ WBTC

Выгода — на сколько процентов больше другой валюты придёт на кошелёк за то, что на руках,
чем за неё отдали. Пока она ниже `SWAP_GAIN_PCT`, курс проверяется раз
в `SWAP_CHECK_MINUTES` минут. Дошла до порога — бот молча взводится, проверяет
раз в минуту и запоминает пик. Одно сообщение приходит, когда:

- выгода откатилась от пика на `SWAP_TRAIL_PCT` п.п. (пик +5%, сейчас +4%);
- или вернулась ниже порога раньше, чем случился откат, — чтобы не упустить цель.

Дальше бот молчит, пока выгода не уйдёт ниже порога, и взводится заново.

После обмена — `/bought 0.31 WBTC`: бот запоминает новую позицию (0.31 WBTC,
отданные за них 10 ETH), сравнивает с прошлой базой и разворачивает слежение
в обратную сторону. Позиция хранится в `SWAP_STATE_FILE`, окружение задаёт только
стартовую; там же — история обменов. `/swap` — текущее положение.

Выгода считается на кошелёк: котировка KyberSwap на всю позицию минус комиссия
кошелька `SWAP_FEE_PCT` и газ. Агрегатор не ответил — рынок CoinGecko минус комиссия.
Bot API не отдаёт ID по username, поэтому чат владельца бот
запоминает, когда тот впервые пишет `/swap` или `/bought`, — до этого уведомлять некуда.

## Деплой

Источник правды — GitHub (`smrmn/mbti-predict`). Push в `main` запускает
`.github/workflows/deploy.yml`, тот заходит на сервер по SSH, и
`deploy/deploy.sh` делает всё остальное:

```bash
git push origin main
```

Скрипт забирает `main` с GitHub в bare-репу, обновляет рабочее дерево
`/opt/mbti-predict`, доставляет зависимости в `.venv` (Python 3.11 через `uv`)
и перезапускает `mbti-predict.service`. Если сервис не поднялся, job в Actions
краснеет с хвостом журнала. Перевыкатить без коммита — Actions → Deploy → Run
workflow, или на сервере `mbti-predict-deploy`.

Прямой push на сервер отключён: `pre-receive` в bare-репе его отклоняет,
чтобы история не разъехалась с GitHub.

| Что | Где |
|---|---|
| Bare-репа (зеркало GitHub) | `/var/repo/mbti-predict.git` |
| Скрипт выкатки | `/usr/local/bin/mbti-predict-deploy` (копия `deploy/deploy.sh`) |
| Доступ Actions к серверу | ключ в `authorized_keys` с `command="mbti-predict-deploy"`; секреты `DEPLOY_SSH_KEY`, `DEPLOY_HOST`, `DEPLOY_KNOWN_HOSTS` |
| Рабочее дерево | `/opt/mbti-predict` |
| Профили пользователей | `/var/lib/mbti-predict/profiles` (`PROFILES_DIR`) |
| Секреты | `/etc/mbti-predict.env` |
| Логи | `journalctl -u mbti-predict -f` |

Данные лежат вне рабочего дерева, поэтому `git checkout -f` при деплое их не трогает.
